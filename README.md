# 🧩 KR Code Reviewer

PR diff를 읽고 한국어로 코드 리뷰 코멘트를 자동 생성하는 CLI 도구 + GitHub Action입니다.

## 기능

- 🔍 `git diff` 파싱 및 변경사항 분석
- 🤖 Anthropic Claude API 기반 코드 리뷰 생성
- 🇰🇷 한국어 리뷰 코멘트 출력
- 💻 CLI로 로컬 diff 리뷰
- 🔗 GitHub PR에 자동 코멘트
- ⚡ GitHub Actions 워크플로우 지원

## 기술 스택

- **Language:** Python 3.11+
- **LLM:** Anthropic Claude API
- **CLI:** Click
- **GitHub 연동:** PyGithub
- **CI/CD:** GitHub Actions
